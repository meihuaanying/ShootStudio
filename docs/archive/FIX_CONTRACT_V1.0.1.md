## 0. 执行纪律

1. **中途不停**：按 §3 阶段顺序 F1→F6 连续执行；每阶段结束一句话汇报；不提问、不等确认。
2. **不许带病推进**：每阶段门禁失败必须原地修复重验；禁止注释掉测试、禁止 --no-verify。
3. **不许缩水**：§2 决策清单每一项都是承诺；实现不了必须记录阻塞原因与满足同等用户价值的替代实现。
4. **用户视角优先**：任何"进程存活"类冒烟不算通过；必须由应用级测试从启动到关键路径跑通。
5. **本地优先 + 中文优先 + 密钥安全**三条底线不变。

## 2. 锁定决策清单（F1–F18）

### 产品体验
- **F1 开案页**：默认首页。极简：一句话输入框 + 「换一批灵感」（点击在输入框下方展开/收起横向灵感卡片）+ 最近策划案列表；生成后先出结果卡片（整体插入/按模块挑选），确认后写入并进入策划编辑器。工作台各模块导航降为二级（导航保留，开案页为第一项且默认）。
- **F2 品质标准**：结构 100% 合法 + 每模块可执行细节（光位参数/姿势口令/时间轴/预算区间/风险提示），人工微调即用。
- **F3 AI 管线**（全部）：
  - 两段式生成：先「推理策划思路」（自由文本，含可执行细节）→ 再「结构化输出」（严格 JSON）；
  - provider 原生结构化输出：OpenAI `json_schema(strict)` / Anthropic `tool_use` / Gemini `responseSchema`；不支持者回退 `json_object` 与纯 JSON 提示；
  - 工作区上下文深度注入：资源库条目（名称+字段）、画板色卡、已存布光方案、收藏姿势（含镜头建议）、模板类目、预算价格区间；
  - 生成后自检评分：结构合法性（必须 100%）+ 细节完整度 + 引用一致性；<80 自动重试 1 次，仍低分标注短板但不阻断；
  - 生成后对话式修订：策划编辑器右侧常驻 AI 侧栏，对话携带策划案摘要+目标模块全文；返回模块级 diff 预览，用户点「应用」才写入；每个模块卡片提供「AI 改写」快捷入口。
- **F4 模块编辑深度**（全部）：
  - 色卡：手动增删、HSV 取色器、从任意图片提取、复制色值；
  - 姿势清单：拖拽排序、替换（从姿势库选择）、移除；
  - 预算：实时自动合计、AI 按城市/类别估算（用内置价格区间，标注「估算值」）；
  - 日照：60+ 城市库 + 手动经纬度 + 在线地名搜索（Nominatim，断网回退并提示）；
  - 参考样片：模块内直接上传图片（落工作区、入色卡、随导出渲染真实图）；
  - 富文本：加粗/无序列表基础格式（轻量标记，长图与 PDF 同步渲染）。
- **F5 技术升级**（全部）：
  - window_manager：标题「正片工坊 ShootStudio」、默认 1440×900、最小 1100×720、启动居中、尺寸位置记忆；
  - 全局异常兜底：FlutterError/PlatformDispatcher 捕获 → logs/app.log（应用目录）+ 友好错误页（错误码可复制）；
  - 引擎懒加载：切到布光/摆姿页才创建 WebView；隐藏页暂停渲染（引擎 `setPaused`）；测试环境跳过 WebView；
  - Shot Planner 式 AI 布光助手：布光页侧栏输入 → 生成灯位/道具 JSON → 预览（灯位图+清单）→ 应用；支持连续迭代；
  - AI 场景感知姿势推荐：姿势库「用场景照推荐」→ 多模态 provider（GPT-4o/通义 VL/Gemini/Claude）→ 3–5 个姿势建议+机位；手动触发、单次调用。
- **F6 首次体验**：三步图文引导 + 双按钮（「开始空白工作区」/「载入示例内容」）；示例内容 = 1 策划案 + 6 参考帧 + 1 布光方案 + 3 资源 + 3 收藏姿势，设置页可一键移除（demo- 前缀标记）。
- **F7 视觉愉悦**：轻量动效体系（160–320ms 统一曲线：页面切换/卡片悬停/生成流光/进度动画）；空态插画（程序绘制）；统一图标风格；灵感流卡片（可展开）。
- **F8 桌面成品**：App 图标定制（脚本生成 ico/png，不用默认 Flutter 标）；单实例运行（第二实例激活已有窗口）；关闭即退出（无托盘）。

### 数据与导出
- **F9 预算价格区间内容包**：新增 `content/budget_refs.json`（城市/场景价格区间）；AI 与本地引擎引用。
- **F10 日照城市库**：`content/cities.json` ≥60 城市（名称/经纬度/时区） + Nominatim 在线搜索 + 经纬度手输。
- **F11 姿势包补全**：每个姿势补 `lens`（已有）与 `cameraPosition`（机位）字段；本地引擎/AI 生成引用。
- **F12 导出保真**：长图渲染用户上传的真实图片（refs/资源封面）；PDF 增加矢量灯位图（俯视图：灯位/指向/被摄体）与富文本格式渲染。
